# Regio: especies en peligro en Chile

🔗 Link al sitio: https://martinafinkenberger.github.io/paginaweb/


---

## Comentarios sobre el proceso de desarrollo y diseño HTML

Para estructurar esta página web utilicé etiquetas de HTML e integré la identidad visual del proyecto grupal directamente mediante estilos internos (<style>), siguiendo la paleta de colores y tipografías establecidas en el sistema visual de la webstory.

---

### 1. Estructura base

Organicé la crónica “Regio: especies en peligro en Chile” a partir de una estructura HTML clara y jerárquica:

- Utilicé la etiqueta <header> para presentar el título principal (<h1>) de la pieza.
- Agrupé el contenido narrativo dentro de un contenedor (<div>) para mantener una lectura ordenada.
- Desarrollé la crónica mediante párrafos (<p>), respetando la progresión narrativa del texto.
- Incorporé subtítulos (<h2>) para separar secciones conceptuales dentro del relato.
- Finalmente, utilicé <footer> para incluir la fuente externa y cerrar la pieza con un elemento informativo.

---

### 2. Integración de la identidad visual

Para asegurar coherencia con la webstory grupal, implementé la identidad visual definida en el sistema del proyecto:

- Se utilizó la tipografía Capriola para títulos y Lora para el texto corrido, importadas desde Google Fonts.
- Se aplicó la paleta de colores institucional:
  - Fondo crema (#FBF8F0) para mantener legibilidad y neutralidad visual.
  - Texto en azul oscuro (#1F3D5B) para asegurar contraste y lectura continua.
  - Elementos destacados en burdeo (#86223E), asociado a énfasis y categorías críticas.
  - Acentos en celeste (#0695D1) para enlaces y referencias externas.

Además, se incorporó una línea divisoria bajo el título principal, utilizando el color burdeo del sistema visual, con el fin de separar la cabecera del inicio del relato y reforzar la jerarquía visual.

---

### 3. Formato del texto

Para mantener el estilo de crónica periodística, todos los párrafos fueron trabajados con alineación justificada (text-align: justify;), lo que permite una lectura más uniforme y formal.

La jerarquía del texto se organiza a través del uso de títulos y bloques narrativos, evitando la fragmentación excesiva y privilegiando un flujo continuo de lectura, propio del formato de crónica.

---

### 4. Integración de la imagen (visualización)

Se incorporó una imagen de apoyo titulada “visualización.jpg”, ubicada estratégicamente dentro del desarrollo del texto.

Uno de los principales desafíos fue asegurar su correcta visualización en GitHub Pages, por lo que se trabajó con rutas relativas, verificando que el archivo estuviera dentro de la misma carpeta del index.html dentro de /docs.

La imagen funciona como complemento visual de la narrativa, reforzando la idea de distribución de especies amenazadas en Chile.

---

### 5. Uso de enlaces externos

Se implementó la etiqueta <a> para incluir una fuente oficial del Ministerio del Medio Ambiente de Chile:

https://clasificacionespecies.mma.gob.cl/

Este enlace se abre en una nueva pestaña (target="_blank") y cumple la función de respaldo informativo, conectando la pieza narrativa con información científica real sobre la clasificación de especies.

---

## Conclusión del proceso

El desarrollo de esta pieza permitió traducir una crónica periodística en un formato web estructurado mediante HTML, integrando narrativa, jerarquía visual e identidad gráfica de manera coherente dentro de una webstory grupal.
